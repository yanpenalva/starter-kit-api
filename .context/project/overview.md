# Project Overview

- Name: `starter-kit-api`.
- Repository: https://github.com/yanpenalva/starter-kit-api
- Purpose: independent REST API for the Starter Kit ecosystem.
- Stage: Laravel 13 API with Sanctum session/CSRF authentication, identity flows, user/role administration, RBAC policies, audit feed, generated OpenAPI, and CI quality/compatibility gates.

- Repository independence: API and frontend are independent repositories, with independent deployments and versioning.
- Reference: `starter-kit-laravue` is exclusively a read-only reference.
